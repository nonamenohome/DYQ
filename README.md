# DYQ

个人折腾项目的聚合仓库。[友朋大QYD] 的项目合集，根目录下每个子文件夹对应一个独立项目。

## 结构

```text
DYQ/
├─ harness-custom/      # DeepSeek Harness 界面定制（壁纸透明 + 页面风格）
└─ README.md            # 本文件
```

> 后续新项目都在根目录下各自建立子文件夹。

## 子项目

### harness-custom
针对 **DeepSeek Harness** Web 界面做的定制：壁纸透明显示、白天/黑夜风格切换、壁纸透明度滑块，以及皮肤插件说明。详见 [harness-custom/README.md](./harness-custom/README.md)。

## 许可证

各子项目的许可证以各自目录内的说明为准；本仓库聚合层不含实质代码。
